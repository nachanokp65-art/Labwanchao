☁️

แก้ข้อมูลไม่ตรงกันระหว่างอุปกรณ์

ถ้าเปิดแอปจากหลายเครื่องแล้วพบว่าข้อมูลไม่ตรงกัน ให้เลือกเครื่องที่มีข้อมูลถูกต้อง/ครบถ้วนที่สุด แล้วกดปุ่มนี้จากเครื่องนั้น — ข้อมูลในเครื่องนี้จะถูกอัปโหลดทับข้อมูลบนคลาวด์ทั้งหมด ทุกอุปกรณ์อื่นจะเปลี่ยนมาใช้ชุดข้อมูลนี้แทนภายในไม่กี่วินาที (ไม่มีข้อมูลอะไรถูกลบ)

🔑 เข้าสู่ระบบ

เปิดแอปแล้วจะพบหน้าเข้าสู่ระบบทันที บัญชีเริ่มต้นของระบบคือ:

  • Username: admin
  • Password: admin

ผู้ดูแลระบบ (Administrator) สามารถเพิ่มผู้ใช้งานใหม่ได้จากหน้า Settings หรือเมนู "เพิ่มผู้ใช้งาน" ในแถบด้านข้าง — ดูรายละเอียดที่หัวข้อ Settings ด้านล่าง

📊 หน้า Dashboard

หน้าแรกที่แสดงภาพรวมของระบบทั้งหมด:

  • Compliance % — เปอร์เซ็นต์เครื่องมือที่บันทึกผลแล้วในวันนี้ เทียบกับจำนวนเครื่องมือทั้งหมด
  • เครื่องทั้งหมด / รอบันทึก — จำนวนเครื่องมือในระบบ และจำนวนที่ยังไม่ได้บันทึกวันนี้
  • เร่งด่วน / เฝ้าระวัง / บันทึกแล้ว — นับจากสถานะล่าสุดของแต่ละเครื่องมือ (อิงบันทึกล่าสุดของเครื่องนั้น ๆ)
  • รายการเครื่องมือทั้งหมด — แสดงสถานะและวันที่บันทึกล่าสุดของแต่ละเครื่อง กดปุ่ม "+ เพิ่มเครื่องมือ" เพื่อเพิ่มเครื่องใหม่ได้ทันที
  • บันทึกล่าสุด — แสดง 5 รายการบันทึกล่าสุดของทั้งระบบ พร้อมไอคอนตามสถานะ

📋 หน้า Report

แบ่งเป็น 2 แท็บ:

  • บำรุงรักษา — ตารางรายงานทุกบันทึกที่เคยบันทึกไว้ ค้นหา/กรองได้ตามเครื่องมือ ช่วงวันที่ ผู้บันทึก และสถานะ กดปุ่ม "+ เพิ่มบันทึก" เพื่อเพิ่มบันทึกใหม่ได้จากหน้านี้เช่นกัน
  • สรุปอุณหภูมิ — สรุปผลอุณหภูมิรายเครื่องมือ (ค่าเฉลี่ย/ต่ำสุด/สูงสุด/จำนวนบันทึกแต่ละสถานะ) กรองตามช่วงวันที่และอุปกรณ์ได้

Export PDF: กดปุ่ม "Export PDF" เพื่อเลือกช่วงวันที่ ระบบจะเปิดหน้าต่างพิมพ์ (ตั้งค่ากระดาษ A4 ให้อัตโนมัติ) เลือกปลายทางเป็น "Save as PDF" / "บันทึกเป็น PDF" ในกล่องพิมพ์ของเบราว์เซอร์ ก็จะได้ไฟล์ PDF จริง

ลบข้อมูลทั้งหมด: ปุ่ม 🗑️ ข้างจำนวนรายการ ใช้ลบประวัติการบำรุงรักษาทั้งหมดออกจากระบบ (มีกล่องยืนยันก่อนลบเสมอ ไม่กระทบเครื่องมือหรือผู้ใช้งาน)

🌡️ หน้า Temperature Log

ใช้บันทึกอุณหภูมิของอุปกรณ์ (เช่น ตู้เย็น ตู้แช่แข็ง) ประจำวัน:

  • กด "+ บันทึกอุณหภูมิ" เลือกอุปกรณ์ (หรือเพิ่มอุปกรณ์ใหม่ผ่านตัวเลือก "+ เพิ่มอุปกรณ์ใหม่") กรอกค่าและวัน-เวลา
  • กดปุ่ม ⚙️ บนการ์ดอุปกรณ์เพื่อ ตั้งช่วงอุณหภูมิปกติ (ต่ำสุด–สูงสุด) ของแต่ละเครื่อง เช่น ตู้เย็น 2–8°C, ตู้แช่แข็ง -25 ถึง -15°C
  • เมื่อตั้งช่วงแล้ว ระบบจะตัดสินสถานะให้อัตโนมัติขณะกรอกค่า: อยู่ในช่วง = ปกติ, เกินช่วงเล็กน้อย = เฝ้าระวัง, เกินมาก = ผิดปกติ และจะเด้งหน้าต่างเตือนก่อนบันทึกทุกครั้งที่ค่าอยู่นอกช่วง
  • หากอุปกรณ์ใดยังไม่ได้ตั้งช่วงอุณหภูมิ ระบบจะไม่ตัดสินให้ ต้องเลือกสถานะด้วยตนเองและตรวจสอบให้ตรงกับค่าที่บันทึกทุกครั้ง
  • 💧 ความชื้น (ทางเลือก) — ในหน้าต่างตั้งช่วงอุณหภูมิ (⚙️) ติ๊ก "ติดตามความชื้นของเครื่องนี้ด้วย" แล้วตั้งช่วงความชื้นปกติ (%RH) เฉพาะอุปกรณ์ที่ต้องควบคุมความชื้นจริง (เช่น ห้อง/ตู้เก็บรีเอเจนต์หรือเอกสาร) เครื่องที่ไม่ติ๊กไว้จะไม่มีช่องกรอกความชื้นให้ เพื่อไม่ให้ฟอร์มรกเกินจำเป็น เมื่อเปิดใช้แล้ว ช่องกรอกความชื้นจะโผล่ในฟอร์ม "บันทึกอุณหภูมิ" โดยอัตโนมัติ และระบบจะตัดสินสถานะโดยใช้ค่าที่ "แย่กว่า" ระหว่างอุณหภูมิกับความชื้นเสมอ
  • อุปกรณ์ที่ติดตามความชื้นอย่างเดียว — ในหน้าต่างตั้งช่วง (⚙️) สามารถปิด "ติดตามอุณหภูมิของเครื่องนี้" ได้ (เหลือเปิดแต่ความชื้น) เหมาะกับห้องเก็บเอกสาร/รีเอเจนต์ที่สนใจแค่ความชื้น ฟอร์มบันทึกจะซ่อนช่องอุณหภูมิให้อัตโนมัติ ต้องเปิดอย่างน้อยหนึ่งอย่างเสมอ (อุณหภูมิ หรือ ความชื้น)
  • สรุปอุณหภูมิ/ความชื้น — ตารางสรุปรายเครื่องมือ (หน้า Report และรายงาน PDF) มีคอลัมน์ "ความชื้นเฉลี่ย" เพิ่มมาด้วย เครื่องที่ไม่มีข้อมูลบางประเภทจะแสดง "-" ในคอลัมน์นั้น
  • Export CSV — ปุ่ม "📤 Export" ที่หน้า Report (ทั้งแท็บบำรุงรักษาและอุณหภูมิ) เลือกช่วงวันที่แล้วกดปุ่ม "📊 CSV" เพื่อดาวน์โหลดเป็นไฟล์ .csv เปิดใน Excel ได้ทันที (ภาษาไทยแสดงถูกต้อง) เหมาะกับการนำไปประมวลผลต่อ ส่วนปุ่ม "📄 PDF" ยังคงใช้สร้างรายงานสำหรับพิมพ์/ยื่นตรวจเหมือนเดิม
  • ตารางด้านล่างค้นหา/กรองตามอุปกรณ์ วันที่ และสถานะได้

🔧 หน้า Maintenance Log

จัดการเครื่องมือ — เพิ่มเครื่องมือใหม่เข้าระบบ (พร้อม S/N ถ้ามี) หรือลบเครื่องมือที่เลิกใช้แล้วออกจากระบบ

Checklist การบำรุงรักษา — เลือกเครื่องมือ เพิ่มรายการตรวจสอบที่ต้องทำ ติ๊กเมื่อทำเสร็จแต่ละรายการ เลือกวันที่บันทึกผล (ค่าเริ่มต้นคือวันนี้) แล้วกด "บันทึกผล Checklist" ระบบจะบันทึกผลลงในประวัติการบำรุงรักษาโดยอัตโนมัติ และรีเซ็ตรายการติ๊กให้พร้อมใช้รอบถัดไป

👥 หน้า Lab Staff

แสดงรายชื่อบุคลากรทั้งหมดในกลุ่มงาน กด "+ เพิ่มบุคลากร" เพื่อเพิ่มรายชื่อใหม่ (เลือกตำแหน่งได้จากรายการที่กำหนดไว้) และกดไอคอน ✕ บนการ์ดเพื่อลบรายชื่อที่ไม่ต้องการ

⚙️ หน้า Settings

  • เพิ่มผู้ใช้งานใหม่ — เฉพาะ Administrator เท่านั้นที่เพิ่มผู้ใช้งานได้ กรอกชื่อ-นามสกุล username/password และเลือกตำแหน่ง
  • ตั้งค่าระบบ — แก้ไขชื่อโรงพยาบาล แผนก จำนวนวันแจ้งเตือนก่อนครบกำหนด และอีเมลแจ้งเตือน
  • ล้างข้อมูลระบบ — ลบข้อมูลทั้งหมดในระบบ (เครื่องมือ, ประวัติบำรุงรักษา, Checklist, อุณหภูมิ, ผู้ใช้งานที่เพิ่มเอง) แล้วเริ่มต้นใหม่ทั้งหมด เฉพาะ Administrator เท่านั้นที่กดได้ (ปุ่มจะจางลงและกดไม่ได้สำหรับบทบาทอื่น) ใช้ด้วยความระมัดระวัง เพราะย้อนกลับไม่ได้
  • จัดการบัญชีผู้ใช้งาน — มองเห็นเฉพาะ Administrator แสดงรายชื่อผู้ใช้งานทุกคนพร้อมปุ่ม "🔑 ตั้งรหัสผ่านใหม่" ต่อคน ใช้ได้โดยไม่ต้องรู้รหัสผ่านเดิม (เช่น กรณีมีคนลืมรหัสผ่าน) ระบบไม่สามารถแสดงรหัสผ่านจริงของใครได้ เพราะเก็บเป็น hash แบบย้อนกลับไม่ได้เพื่อความปลอดภัย

📏 กฎการบันทึกข้อมูล

  • บันทึกย้อนหลังได้ไม่เกิน 2 วัน — ใช้กับทุกจุดที่เลือกวันที่เองได้ (บันทึกการบำรุงรักษา, บันทึกอุณหภูมิ, บันทึกผล Checklist) ตัวเลือกวันที่จะถูกล็อกไม่ให้เลือกวันที่เก่ากว่านี้โดยอัตโนมัติ
  • แจ้งเตือนเมื่อมีการบันทึกซ้ำ — ถ้าเครื่องมือนั้นมีบันทึกในวันเดียวกันอยู่แล้ว ระบบจะถามยืนยันก่อนบันทึกซ้ำเสมอ เพื่อป้องกันการบันทึกซ้ำโดยไม่ตั้งใจ

✨ ฟีเจอร์เสริม

  • สลับภาษา ไทย / English — กดปุ่ม EN / TH มุมขวาบน (หน้าล็อกอินก็มี) ระบบแปลเมนู ปุ่ม ฟอร์ม และข้อความแจ้งเตือนหลัก ส่วนข้อมูลที่บันทึกไว้ (ชื่อเครื่องมือ ผู้บันทึก วันที่) และหน้าคู่มือนี้ยังเป็นภาษาไทย ข้อมูลที่เก็บจริงเป็นภาษาไทยเสมอ สลับภาษาไปมาได้โดยข้อมูลไม่เสียหาย
  • Dark mode — กดปุ่ม 🌙 / ☀️ มุมขวาบน ระบบจำค่าที่เลือกไว้ในอุปกรณ์นั้น และถ้ายังไม่เคยเลือกจะตามการตั้งค่าของเครื่อง
  • QR Code ประจำเครื่องมือ — หน้า Maintenance Log → ปุ่ม 🔳 QR Code ใส่ URL ของเว็บที่โฮสต์ระบบ แล้วพิมพ์ป้ายไปแปะที่ตัวเครื่อง เมื่อสแกนและเข้าสู่ระบบ ระบบจะเปิดฟอร์มบันทึกของเครื่องนั้นให้ทันที (ต้องเปิดระบบจากเว็บ ไม่ใช่ไฟล์ในเครื่อง)
  • Template Checklist — ในส่วน Checklist เลือกเครื่องต้นทางแล้วกด "คัดลอกมาที่นี่" หรือใช้ Export / Import เป็นไฟล์ JSON เพื่อส่งต่อให้เครื่องอื่น รายการที่ซ้ำกับของเดิมจะถูกข้าม
  • สรุประยะยาว — ที่หน้า Dashboard แสดง % Compliance จำนวนครั้งที่อุณหภูมิผิดปกติ และเครื่องมือที่มีปัญหาบ่อย ย้อนหลัง 6 เดือนหรือ 4 ไตรมาส

📱 การใช้งานบนมือถือ

หน้าจอปรับให้เหมาะกับมือถือโดยอัตโนมัติ — เมนูด้านข้างจะเปลี่ยนเป็นแถบเมนูด้านล่างจอ ฟอร์มและปุ่มต่าง ๆ ขยายให้กดง่ายขึ้น และตารางสามารถเลื่อนซ้าย-ขวาเพื่อดูข้อมูลครบทุกคอลัมน์ได้

💾 การเก็บและสำรองข้อมูล

ข้อมูลทั้งหมดถูกเก็บไว้ใน localStorage ของเบราว์เซอร์ที่ใช้งานอยู่ (ไม่ได้อยู่บนเซิร์ฟเวอร์ส่วนกลาง) ดังนั้น:

  • ข้อมูลจะยังอยู่เหมือนเดิมทุกครั้งที่เปิดเว็บใหม่ ตราบใดที่ใช้เบราว์เซอร์/อุปกรณ์เดิม และไม่ได้ล้างข้อมูลเบราว์เซอร์
  • ถ้าเปลี่ยนเบราว์เซอร์หรืออุปกรณ์ ข้อมูลจะไม่ถูกซิงก์ตามไปด้วย
  • แนะนำให้ Export PDF รายงานสำคัญเก็บไว้เป็นระยะ เผื่อกรณีต้องล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนอุปกรณ์
